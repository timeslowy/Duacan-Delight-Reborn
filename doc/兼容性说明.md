# 兼容性与数据包边界说明

本文档记录本模组对**其他模组数据**和**原版命名空间**的介入范围，供整合包作者与维护者参考。

---

## 1. 必需依赖

以下模组为 **required**，缺失时游戏无法启动（见 `META-INF/neoforge.mods.toml`）：

| 模组 | modid | 说明 |
| --- | --- | --- |
| NeoForge | `neoforge` | 加载器 |
| Minecraft | `minecraft` | 1.21.1 |
| 农夫乐事 | `farmersdelight` | 核心前置，大量配方依赖其序列化器 |
| 额外乐事 | `extradelight` | 核心前置，晾干/研磨/搅拌等配方依赖 |

---

## 2. 可选集成

以下模组为 **optional**。**装了就加载对应配方，没装则整条配方被跳过**，不会报错。

| 模组 | modid | 本模组提供的内容 |
| --- | --- | --- |
| 料理乐事 | `cuisinedelight` | 3 个拼盘配方、配料配置 |
| 烧烤乐事 | `barbequesdelight` | 1 个烤制配方 |
| 屠宰工艺 | `butchercraft` | 生猪屠宰配方 + 战利品表（见下方注意） |
| 蟹农乐事 | `crabbersdelight` | 蟹笼战利品表、JEI 展示标签 |
| 机械动力 | `create` | 1 个粉碎配方 |
| 随意乐事 | `casualness_delight` | 4 个油炸配方 |
| 龙之生存 | `dragonsurvival` | 龙族食物营养数据 |
| 饺子乐事 | `dumplings_delight` | 大蒜等食材引用 |

### 条件化机制

所有可选集成的 `recipe` 文件都在**顶层**加了：

```json
"neoforge:conditions": [
  { "type": "neoforge:mod_loaded", "modid": "<modid>" }
]
```

### 注意：战利品表与标签无法条件化

NeoForge 的 `TagFile` 与 `LootTable` **不支持**顶层条件（只有战利品表的 `functions` 支持元素级条件）。因此：

- `data/butchercraft/loot_table/meat_hook/butcher_pig.json` 引用了 butchercraft 自身物品（`pork_scraps` 等）。**未安装 butchercraft 时该表解析失败，日志会留下一条报错**，但不影响启动与其他内容。
- `data/dragonsurvival/data_maps/...` 属于 Dragon Survival 的 data map 类型。NeoForge 的 `DataMapLoader` 对不存在的 data map 类型只打一条 `warn` 并跳过（`DataMapLoader.java` 第 157-161 行），**不会报错**，因此无需条件。
- `data/crabbersdelight/tags/...` 只引用本模组物品，缺失该模组时仅为无人读取的孤立标签，无副作用。

## 3. 原版命名空间覆盖

本模组当前覆盖了以下**原版**数据。这是有意为之的功能，但会全局影响整合包。

### 3.1 村庄农田（5 个 processor_list）

```
data/minecraft/worldgen/processor_list/farm_desert.json
data/minecraft/worldgen/processor_list/farm_plains.json
data/minecraft/worldgen/processor_list/farm_savanna.json
data/minecraft/worldgen/processor_list/farm_snowy.json
data/minecraft/worldgen/processor_list/farm_taiga.json
```

在原版规则末尾追加了一条：`wheat` / `potatoes` 各有 60% 概率被替换为 `duacan_delight:gaicai_crop`。

**影响**：所有使用原版村庄农田的存档都会出现盖菜。若整合包另有修改农田的模组，二者会互相覆盖（后加载者生效）。

### 3.2 已移除的覆盖

以下覆盖**曾经存在，现已改为无侵入方案或删除**：

| 项目 | 原做法 | 现做法 |
| --- | --- | --- |
| 竹笋掉落 | 整个替换 `minecraft:blocks/bamboo_sapling` 战利品表 | 改为 `neoforge:add_table` 战利品修改器，原版 `minecraft:bamboo` 掉落保留 |
| 红树林纹理 | 覆盖 `assets/minecraft/textures/block/stripped_mangrove_log.png` | 已删除（与 vanilla 逐字节相同，纯冗余） |
| 银耳自然生成 | 森林 random_patch（实际 100% 失败） | 已移除，改由孢子右键原木种植 |
| 盖菜自然生成 | 森林 random_patch（实际 100% 失败） | 已移除，仅通过村庄农田出现 |

| 命名空间 | 是否本模组 | 说明 |

| `duacan_delight` | ✅ 自有 | 主体内容 |

| `farmersdelight` / `extradelight` | ⚠️ 注入 | 必需前置的配方注入 |
| `cuisinedelight` 等 8 个 | ⚠️ 注入 | 可选集成，已条件化 |
